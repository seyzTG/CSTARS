# CSTARS

Telegram-бот с мини-играми на внутренний баланс: кости, футбол, баскетбол, дартс, боулинг, слоты, «21 Очко» и Crash. Внутри есть чеки, партнёрская программа, ежедневные бонусы, кешбэк, рейтинг игроков и админ-панель.

Написан на **Python 3.12+ / aiogram 3 / SQLAlchemy 2 + Alembic / PostgreSQL (SQLite для разработки) / Redis**, покрыт тестами на pytest.

> ⚠️ **Важно.** Проект опубликован как открытый исходный код для изучения и экспериментов. Прочитайте раздел [Ответственность](#ответственность) перед тем, как запускать бота с реальными платежами.

## Возможности

**Игры**

| Игра | Механика |
|---|---|
| Кости | Тотал и диапазон, чёт/нечёт, точное число |
| Футбол, Баскетбол, Дартс, Боулинг | Бросок через официальный `send_dice` Telegram, исходы и коэффициенты задаются в конфиге |
| Слоты | Комбинации с множителями |
| 21 Очко | Раздача против дилера, колода на `secrets` (CSPRNG) |
| Crash | Ракета с растущим множителем: нужно забрать ставку до взрыва |
| Авторские режимы | Исходы и веса задаёт администратор командой `/modes` |

**Остальное**

- Балансы с разделением на основной и бонусный кошелёк
- Пополнение через Telegram Stars, Crypto Bot и xRocket
- Заявки на вывод с очередью для администратора и аудит-логом
- Чеки: создание и активация по ссылке
- Реферальная программа, ежедневный бонус, кешбэк, топ игроков
- Premium Custom Emoji и цветные кнопки с запасным Unicode-вариантом
- Защита финансовых операций: условные `UPDATE` (баланс не уходит в минус), идемпотентные платёжные колбэки, троттлинг

## Быстрый запуск

**Что понадобится:** Python 3.12+, токен бота от [@BotFather](https://t.me/BotFather) и ваш Telegram ID (узнать можно у [@userinfobot](https://t.me/userinfobot)).

### Windows / Linux, без Docker

```bash
git clone https://github.com/<ваш-логин>/cstars.git
cd cstars

python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux:   source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env     # Windows: copy .env.example .env
# откройте .env и заполните BOT_TOKEN, BOT_USERNAME, ADMIN_IDS

python -m app.main
```

Для быстрой проверки можно использовать SQLite: раскомментируйте в `.env` строку `DATABASE_URL=sqlite+aiosqlite:///./dev.db`. Таблицы создаются автоматически, если включён `AUTO_CREATE_TABLES=true`; иначе выполните `alembic upgrade head`.

### Docker Compose (PostgreSQL + Redis + бот)

```bash
cp .env.example .env
# заполните .env
docker compose up -d --build
docker compose logs -f bot
```

Миграции применяются автоматически перед стартом.

## Настройка (.env)

Все параметры описаны комментариями в `.env.example`. Основные:

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен от BotFather. **Никому не показывайте и не коммитьте** |
| `BOT_USERNAME` | юзернейм бота без `@` (нужен для реферальных ссылок) |
| `ADMIN_IDS` | Telegram ID администраторов через запятую |
| `DATABASE_URL` / `DB_*` | подключение к базе данных |
| `USE_REDIS` / `REDIS_URL` | хранилище FSM; без Redis используется память процесса |
| `UNITS_PER_STAR` | курс внутренних единиц к Telegram Stars |
| `BET_MIN` / `BET_MAX` | лимиты ставок |
| `CRASH_*` | параметры Crash: множители, комиссия, длительность полёта |
| `CHECK_MIN` / `CHECK_MAX` | лимиты чеков |
| `REFERRAL_PERCENT` | доля партнёрской программы |
| `WITHDRAW_*` | лимиты и комиссия вывода |
| `CRYPTOBOT_API_KEY`, `XROCKET_API_KEY` | ключи платёжных провайдеров (по желанию) |

### Платежи

- **Telegram Stars**: включите в @BotFather → Bot Settings → Payments. Зачисление происходит только после `successful_payment` с серверной проверкой суммы и `payload`; повторные колбэки отсекаются.
- **Crypto Bot** и **xRocket**: нужны API-ключи. Без ключа метод помечается как `not_configured`, ничего не ломается.

### Коэффициенты и тексты

- Игры, исходы и вероятности: `app/config/games.py`
- Бонусы, кешбэк, рефералы: `app/config/bonuses.py`, `cashback.py`, `referral.py`
- Все тексты и название бота: `app/config/texts.py`
- Ссылки на канал и поддержку в `texts.py` заменены заглушками, укажите свои.

Часть параметров помечена `verified=False`; их список выводит функция `unverified_parameters()` в `games.py`. Проверьте их и подстройте под себя.

## Админ-команды

```
/admin     панель и статистика        /stats      цифры проекта
/wd        очередь заявок на вывод    /user <id>  карточка игрока
/block <id> /unblock <id>             /bonus <id> <сумма>
/coef <игра> <исход> <значение>       /coeflist   переопределения
/modes     авторские режимы           /addmode <code> | <название> | [JSON исходов]
/audit     аудит-лог                  /errors     последние ошибки
```

Права проверяются на сервере по `ADMIN_IDS`, а не по наличию кнопки. Финансовые действия администратора записываются в `admin_actions`.

## Custom Emoji

Бот умеет использовать собственный пак Premium Custom Emoji. Чтобы создать свой:

1. `python scripts/create_emoji_pack.py`: рисует иконки, загружает их и создаёт набор.
2. `python scripts/harvest_emoji_ids.py`: считывает ID и записывает в `custom_emoji_ids.json` и `.env`.
3. Перезапустите бота.

Если ID для какой-то иконки нет, бот использует обычный Unicode-эмодзи.

## Тесты

```bash
python -m pytest
```

Тесты покрывают регистрацию, меню, математику игр, Crash, атомарность журнала, параллельные списания, идемпотентность платежей, чеки, бонусы, рефералов, вывод и права администратора.

## Безопасность

- Секреты хранятся только в `.env`, файл добавлен в `.gitignore`. Если токен когда-либо попадал в публичный доступ, перевыпустите его у BotFather (`/revoke`).
- Токены и ключи маскируются в логах.
- SQL выполняется только через параметры SQLAlchemy.
- Двойное списание исключено условным `UPDATE` и ключами идемпотентности.
